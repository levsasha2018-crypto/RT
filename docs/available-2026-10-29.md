## Проверено без платы

- Все девять статических проверок занятия 2.3 (кроме аппаратной 2.3.8) проходят локально.
- Сборки с Pico SDK 2.3.0 и GCC 15.2.1 проходят с `-Wall` без предупреждений.
- Размеры `.bin`: шаблон — **38288 Б**, две кнопки — **38616 Б**, АЦП — **39712 Б**.
- Без профилирования шаблон занимает **37592 Б**; символов `profiling_start` и
  `profiling_stop` в этом образе нет.
- Намеренное добавление `pico/stdlib.h` в `logic/api/api.c` и `libs/logging/src/log.c`
  в отдельной тестовой копии останавливает обе сборки. Основные исходники не изменены.
- RP2040js запускает собранные ARM-прошивки: проверены команды, расчёт π,
  профилирование, две кнопки, дребезг, короткое и долгое нажатия, АЦП и телеметрия.
- Скрипты графиков выполнены на отдельной математической модели RC-цепи.
  Модельные CSV и результаты остались вне папки сдаваемого проекта.

не создаются из выдуманных показаний. Эти задания проверятся после записи
настоящих файлов. Их workflow запускаются при изменении файлов опыта либо вручную.

## Сборка

Из папки репозитория:

```powershell
./tools/build.ps1 -Project 231-firmware-template
./tools/build.ps1 -Project 239-two-buttons
./tools/build.ps1 -Project 311-adc
```

Профилирование можно выключить строкой `PROFILING_ENABLED=0` в `CMakeLists.txt`
или отдельной сборкой с `-DPROFILING_ENABLED=0`.

Для скриптов компьютера нужны `pyserial` и `matplotlib`:

```powershell
python -m pip install -r 311-adc/requirements.txt
```
