прошивка `311-adc`, версия 1.3.0. Сохранение и отправка продолжены 5 ноября

При каждой подтверждённой конфигурации команда `get_voltage` выполнена пять раз:

| Соединение | Напряжение, В |
| --- | --- |
| GP26 (31) — AGND (33) | 0.010, 0.010, 0.010, 0.011, 0.010 |
| GP26 (31) — 3V3(OUT) (36) | 3.299, 3.299, 3.299, 3.299, 3.299 |

Перемычка затем снята. В официальном логе `device-3-1-1.log` свободный вход
дал 0.587, 0.552 и 0.576 В. Свободный аналоговый вход не задаёт фиксированного
напряжения. Полный обмен ручных проверок сохранён в `311-adc/adc-endpoints.json`.
