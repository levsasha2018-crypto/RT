# Неделя 7: задания 2.3.1–2.3.4

По программе занятия 2.3 первая неделя заканчивается заданием 2.3.4.
Задания 2.3.5–2.3.9 относятся ко второй неделе этого занятия.
Источник: [книга курса, занятие 2.3](https://github.com/ant-lab-ru/es-book/tree/master/Модуль%202.%20Разработка%20ВПО/Занятие%202.3).
Требования сверены с книгой и официальными проверками 22 октября 2026 года.

## Что реализовано

| Задание | Реализация |
| --- | --- |
| 2.3.1 | `stdio-text-protocol` читает один символ без ожидания, делает эхо, обрабатывает Backspace 0x08 и 0x7f, CR/LF, пробелы, ограничение 63 символа и 4 аргумента. `api` ищет команду в таблице и печатает справку и ошибки |
| 2.3.2 | `led-task` содержит состояния OFF, ON, BLINK и действия при входе. Команды меняют состояние или период 1…4294967295 мс. Переключения привязаны к сетке периода; пропущенные переключения не догоняются |
| 2.3.3 | `button-task` читает GP15 с подтяжкой вверх. Машина из четырёх состояний подтверждает нажатие и отпускание после 20 мс стабильного уровня. Удержание не повторяет нажатия; нажатие переводит LED по кругу OFF → ON → BLINK → OFF |
| 2.3.4 | `pi-task` вычисляет ряд Лейбница порциями по 16 членов. `pi_start` отвечает сразу, `pi` сообщает состояние или результат. Повторный запуск во время расчёта отклоняется. При подсчёте конца порции нет переполнения возле UINT32_MAX |

Опыты с памятью и частотами, собственный линкер-скрипт, старые модули LED и clock,
команды version, ping и calc_pi в новый проект не перенесены.
Паспорт начинается с имени и версии, номер платы читается из Pico.

На этой вехе по условию остаются команды `main_time_exec` и `main_time_reset`
из занятия 2.2. Полный набор секундомеров, библиотеки и разделение на `platform`
и `logic` вводятся заданиями следующей недели.

## Сборка

```powershell
. ./tools/enter-environment.ps1
./tools/build.ps1 -Project 231-firmware-template
```

Или стандартно, с установленными инструментами и заданным `PICO_SDK_PATH`:

```powershell
cmake -S 231-firmware-template -B 231-firmware-template/build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build 231-firmware-template/build
```

Сборка с Pico SDK 2.3.0 и GCC 15.2.1, с ключом `-Wall`, прошла без предупреждений.
Размер `.bin` — 38296 байт, меньше ограничения 48 КиБ.
Готовая прошивка: `231-firmware-template/build/231_firmware_template.uf2`.

## Проверка на Pico

Для дополнительных ручных наблюдений запишите UF2 через BOOTSEL.
Кнопка должна замыкать GP15 на GND. Светодиод встроенный, GP25.

```text
help
info
led_period 2000
led_enable
led_disable
led_blink
button
pi_start
uptime
pi
```

Во время расчёта `uptime` отвечает, LED мигает, кнопка меняет его состояние.
Нажмите кнопку несколько раз: счётчик `presses` увеличивается ровно на одно
на каждое устойчивое нажатие. После расчёта `pi` печатает `3.141591654`
с длительностью, измеренной именно на этой плате.

Числовые аргументы принимаются только десятичными цифрами, без знака и префикса.
Например, `led_period -1`, `led_period +5`, `led_period 0x10` и
`led_period 4294967296` отклоняются; `led_period 0` получает отдельную ошибку.
